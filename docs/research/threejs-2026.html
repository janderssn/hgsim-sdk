What changes the target

The current hgsim captures are below the demonstrated browser quality bar. Natural geology, dense canopy, lit aerial impostors and coherent atmosphere must become acceptance criteria.

Nanite Forest and Bruno Simon demonstrate rich navigable worlds. Their asset design, lighting, LOD and delivery pipelines matter more than copying headline triangle or tree counts.

Hgsim needs runtime-lit tree impostors with elevation views for overhead flight. Four side views with baked BasicMaterial lighting cannot provide the required canopy or near/far consistency.

A polished 60–90 second launch-to-landing corridor should precede world expansion. Test it in motion on a named hardware GPU at fixed resolution; retain SwiftShader as a compatibility regression check.

Scope & confidence

How to read this research

Checked 8 November 2026. A project available in 2026 may have started earlier; dates on cards describe source activity, not necessarily release dates.

  1. This is a curated twenty-project benchmark set prioritized for hgsim, not an official worldwide popularity ranking. It deliberately includes authored experiences, real-time world systems, authoring tools and appearance-ceiling renderers.
  2. Every counted entry has primary-source Three.js evidence in code, package metadata or creator implementation documentation. Repository commits are pinned; activity dates do not imply every project first released in 2026. Historical studies are marked.
  3. The current official gallery also includes custom renderers. Tidewater is excluded from the strict twenty because its present source uses its own WebGPU/WGSL engine. A gallery listing alone is not sufficient engine proof.
  4. Live application hosts are outside this cloud network allowlist. Repository code, manifests, documentation and available creator captures were inspected; remote demos and hardware FPS were not independently benchmarked.
  5. Author timing figures retain GPU, resolution, preset, reconstruction and measurement context. Progressive stills, captured splats, tiny composed scenes and logical instance counts are not moving-game frame-rate guarantees.
  6. Code licensing and content licensing are recorded separately. Preview images are remote attributed research references, not hgsim assets or newly rendered screenshots.
  7. Three r187 was released on 30 October 2026. Hgsim currently vendors r180 and GLSL onBeforeCompile patches; several modern WebGPU/TSL references require a deliberate migration. Better art, terrain, lit impostors and many atmosphere techniques can also be built on WebGL2.
Research references retain their creators’ ownership. A repository’s code license does not automatically license its example models, textures, captures or music. External images are linked from their public source repositories; no third-party artwork is bundled here.
